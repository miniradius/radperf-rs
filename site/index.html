Install radperf

Standalone binary

Download a binary and SHA256SUMS for Linux amd64, Linux arm64, or macOS arm64. Make the binary executable and put it on your PATH as radperf.

FreeRADIUS dictionary setup ↗

Docker

The image includes the FreeRADIUS dictionary. Build it from a repository checkout.

docker build -t radperf-rs .
docker run --rm radperf-rs --version

All-in-one RADIUS tools image

docker-radius-tools bundles RADIUS utilities, including eapol_test, radclient, radcrypt, radeapclient, radlast, radperf, radsecret, radsniff, radsqlrelay, radtest, radwho, radzap.

docker run --rm ghcr.io/miniradius/docker-radius-tools:latest eapol_test -v

Run a PAP test with 10,000 users

Point radperf at your test server and use its shared secret. Configure the server to accept user1 through user10000, each with its username as the password.

Command

radperf -d /usr/share/freeradius \
  -u 10000 -s 127.0.0.1:1812 auth testing123
