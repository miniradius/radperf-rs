Install radperf-rs

Standalone binary

Download a binary and SHA256SUMS for Linux amd64, Linux arm64, or macOS arm64. Make the binary executable and put it on your PATH as radperf. Standalone binaries require an external FreeRADIUS dictionary.

FreeRADIUS dictionary setup ↗

Docker

The image includes the FreeRADIUS dictionary. Build it from a repository checkout.

docker build -t radperf .
docker run --rm radperf --version

Build from source

Requires Rust 1.85 or newer. Run this command from a repository checkout. The binary is written to target/release/radperf.

cargo build --locked --release

All-in-one RADIUS tools image

docker-radius-tools bundles RADIUS utilities, including eapol_test, radclient, radcrypt, radeapclient, radlast, radperf, radsecret, radsniff, radsqlrelay, radtest, radwho, radzap.

docker run --rm \
  ghcr.io/miniradius/docker-radius-tools:latest \
  radperf -v

Quick start

To run a PAP test with one million users, point radperf at your test server and use its shared secret. Configure the server to accept user1 through user1000000, each with its username as the password.

Command

radperf -d /usr/share/freeradius \
  -u 1000000 -s 127.0.0.1:1812 auth testing123

To see only the summary in your terminal, append 2>radperf.log to save response logs and errors to a file.

Rust vs. C benchmark

radperf-rs 0.1.1 (Rust) and RadPerf 2.0.1 (C) ran in a QEMU Linux amd64 guest against the same local UDP responder. Each result comes from one completed run of 1,000,000 PAP requests, using the same credentials throughout.

This benchmark compares the C and Rust implementations under the same test conditions. Measuring peak throughput requires a separate bare-metal benchmark, where both implementations may achieve substantially higher throughput.
